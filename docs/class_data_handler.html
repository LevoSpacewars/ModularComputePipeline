Detailed Description

A class that manages a collection of FutureData objects, allowing for deferred initialization and retrieval of data by ID.

Note
This class provides methods to add, retrieve, check readiness, and remove data associated with a unique ID.
It uses an unordered_map to store FutureData objects, allowing for efficient access and management.
The class also provides a method to request a FutureDataPtr for a specific ID, which can be used to manage the FutureData object.
The class uses static assertions to ensure that the type T is not a pointer and is convertible to std::any.
