Detailed Description

Define a function pointer for the init function.

Class that dynamically loads plugins (in the form of shared libraries) at runtime.

Note
To load and use a plug in one must 1. load the plugin 2. define an alias for a function pointer type 3. create a variable to contain the function
pluginManager PG();
void *plugin_test = PG.loadPlugin("plugins/plugin_test.so"); // Specify plugin directory
using someFunCast = void (*)(); // define alias
someFunCast init = reinterpret_cast<someFunCast>(dlsym(plugin_test, "init")); //assign variable
init(); // call function
