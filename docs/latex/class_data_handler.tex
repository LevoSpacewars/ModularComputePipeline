\doxysubsection{Detailed Description}
A class that manages a collection of \doxylink{class_future_data}{Future\+Data} objects, allowing for deferred initialization and retrieval of data by ID. 

\begin{DoxyNote}{Note}
This class provides methods to add, retrieve, check readiness, and remove data associated with a unique ID. 

It uses an unordered\+\_\+map to store \doxylink{class_future_data}{Future\+Data} objects, allowing for efficient access and management. 

The class also provides a method to request a \doxylink{class_future_data_ptr}{Future\+Data\+Ptr} for a specific ID, which can be used to manage the \doxylink{class_future_data}{Future\+Data} object. 

The class uses static assertions to ensure that the type T is not a pointer and is convertible to std\+::any. 
\end{DoxyNote}
