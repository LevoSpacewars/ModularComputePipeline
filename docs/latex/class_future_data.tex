\doxysubsection{Detailed Description}
A class that encapsulates a future data value, allowing for deferred initialization and retrieval. It uses std\+::any to store the value, enabling it to hold any type of data. 

\begin{DoxyNote}{Note}
This class is not thread-\/safe and should be used in a single-\/threaded context or with appropriate synchronization. 

The class provides methods to check if the data is ready, set a value, and retrieve the value. 

The class also provides a pointer wrapper (\doxylink{class_future_data_ptr}{Future\+Data\+Ptr}) for easier management of the \doxylink{class_future_data}{Future\+Data} object. 

The class uses static assertions to ensure that the type T is not a pointer and is convertible to std\+::any. 
\end{DoxyNote}
